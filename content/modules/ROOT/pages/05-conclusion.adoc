= Conclusion (15 Minutes)

このワークショップでは、以下の内容を学びました。

* OpenShift Console を使ってアプリケーションをデプロイする方法
* Kustomize と Helm を使って GitOps で Applications をデプロイする方法
* GitOps ApplicationSets を活用して Applications を動的に生成する方法
* プラットフォームソリューションの一部としてデプロイするために必要な、高度な GitOps 設定とテクニック
* OpenShift Pipelines を使って、サプライサイドのソフトウェアチェーンを検証しながらアプリケーションをビルドする方法
* SigStore をベースとした Red Hat Trusted Artifact Signer (RHTAS) を活用して、署名済み image を検証する方法
* Red Hat Advanced Cluster Security を使って、署名済み image を必須とするポリシーを強制する方法

このワークショップを楽しんでいただけたなら幸いです。
