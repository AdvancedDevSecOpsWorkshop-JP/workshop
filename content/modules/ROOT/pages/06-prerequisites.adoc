= Prerequisites

このワークショップの各モジュールは、前のモジュールで実施した作業に依存しています。
本セクションでは、時間の都合、技術的な問題、または講師が短縮版で進行するなどの理由で先に進む必要がある場合に備えて、前モジュールで必要となる作業を整理します。

== Module 1 - OpenShift as an Application Platform

このモジュールでは、OpenShift console とコマンドラインを使ってアプリケーションをデプロイする方法を学びます。
ここで行う OpenShift へのログインと、ワークショップ用の git リポジトリのクローンは、以降のすべてのモジュールで必要になります。

* OpenShift console にはこちらからアクセスします:

link:{openshift_console_url}[{openshift_console_url},window='_blank']

* console には *Keycloak* プロバイダーでログインします:

image::ocp-app/openshift_login.png[width=80%]

[IMPORTANT]
誤って `htpasswd_provider` オプションでログインしてしまうと、Keycloak で OpenShift にログインできなくなります。
その場合は、Keycloak で再ログインする前に、講師に依頼して OpenShift の user と identity を削除してもらってください。

* ユーザー名 `{user}`、パスワード `openshift` を使用します。

* OpenShift Console では、右上のユーザー名をクリックし、`Copy login command` を選択します:

image::ocp-app/oc_login_command.png[width=80%]

* 表示されたコマンドをターミナルに貼り付けて、OpenShift にログインします。

* 最後に、以下のコマンドで `workshop` リポジトリをクローンします:

[.console-input]
[source,bash,subs="attributes+,+macros"]
----
git clone -b main --single-branch https://gitea-gitea.{subdomain}/user1/workshop ~/workshop
----

== Module 2 - Introduction to GitOps

このモジュールでは GitOps の入門として、kustomize、helm、ApplicationSets を使ったアプリケーションのデプロイ方法を紹介します。
ここでデプロイするアプリケーションは Module 4 で必要になります。

* ApplicationSet を使って Coolstore Application をデプロイします。

[.console-input]
[source,sh,subs="attributes",role=execute]
----
sed 's/$USER/{user}/' ~/workshop/content/modules/ROOT/examples/coolstore-gitops-appset.yaml | sed 's/$SUBDOMAIN/{subdomain}/' | oc apply -f - -n {user}-argocd
----

* Module 4 でフロントエンド image をビルドするために必要となる Pipeline をデプロイします。

[.console-input]
[source,bash,subs="attributes+,+macros"]
----
sed 's/$USER/{user}/' ~/workshop/content/modules/ROOT/examples/pipeline-helm-app.yaml | sed 's/$SUBDOMAIN/{subdomain}/' | oc create -f - -n {user}-argocd
----
